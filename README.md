# 和暦⇔西暦 変換（Chrome拡張）

ページ上で和暦または西暦を選択すると、近くにツールチップで変換結果を表示します。ツールチップをクリックするとクリップボードにコピーします。

- 例: `令和6年3月15日` → `2024年3月15日（金）` / `2024/3/15` → `令和6年3月15日（金）`
- 日付まで含む場合は曜日も表示（明治5年以前は旧暦のため表示しません）
- 改元をまたぐ年・月は両方の元号を併記（`1989年` → `平成元年／昭和64年`）
- 存在しない年・日付、元号の範囲外は警告を表示
- 対応書式: `令和6年` `令和元年3月` `R6` `平3` `2024年3月` `2024/3/15` `2024-03-15` `2024.3.15` など

## インストール（開発者モード）
`chrome://extensions` → デベロッパーモード → 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択。

## テスト
`npm test`（Node 18+、変換ロジックのみ）
