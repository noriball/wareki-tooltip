# 和暦⇔西暦 変換（Chrome拡張）

ページ上で和暦または西暦を選択すると、近くにツールチップで変換結果を表示します。ツールチップをクリックするとクリップボードにコピーします。

- 例: `令和6年3月15日` → `2024年3月15日（金）` / `2024/3/15` → `令和6年3月15日（金）`
- 日付まで含む場合は曜日も表示（明治5年以前は旧暦のため表示しません）
- 改元をまたぐ年・月は両方の元号を併記（`1989年` → `平成元年／昭和64年`）
- 存在しない年・日付、元号の範囲外は警告を表示
- 対応書式: `令和6年` `令和元年3月` `R6` `平3` `2024年3月` `2024/3/15` `2024-03-15` `2024.3.15` など
- 漢数字（`令和六年三月十五日` `二〇二四年` `明治二十五年` `廿五`）に対応
- 江戸時代の元号（慶長〜慶応）に対応。旧暦のため**年のみ換算**し、月日は換算しません（`嘉永6年 → 1853年`、`1864年 → 元治元年／文久4年`）
- 全角数字・全角記号（`令和６年３月１５日`、`２０２４／３／１５`）や `㋿` `㍻` などの合字にも対応

## 出力書式の設定
拡張機能の「オプション」（`chrome://extensions` → 詳細 → 拡張機能のオプション、または拡張機能アイコンの右クリック → オプション）で、**書式テンプレート**を書いて変更できます。変更はすぐ保存され、Chromeにログインしていれば他の端末にも同期されます。

- 「西暦で出力するとき（和暦→西暦）」と「和暦で出力するとき（西暦→和暦）」で別々に設定します。
- よく使う書式はボタンで入力でき、トークンもボタンでカーソル位置に挿入できます。
- コピーする文字列に曜日を含めるかも、それぞれ選べます。

出力したい形を、トークンを `{ }` で囲んで書きます。`{ }` の外に書いた文字は、そのまま出力されます。トークンの大文字小文字は区別しません（`{yyyy}` も可）。

| トークン | 出力 |
|---|---|
| `{YYYY}` | 西暦4桁（2024） |
| `{era}` / `{abbr}` | 元号名（令和） / 略記（R） |
| `{eyear}` / `{eyear2}` | 和暦の年（6、元年は「元」） / 2桁（06） |
| `{M}` / `{MM}` | 月（3） / 2桁（03） |
| `{D}` / `{DD}` | 日（5） / 2桁（05） |
| `{W}` / `{WW}` | 曜日（金） / 曜日の名前（金曜日） |
| `{{` / `}}` | 文字としての `{` と `}` |

例:
- `{YYYY}/{MM}/{DD}({W})` → `2024/03/15(金)`
- `{YYYY}{MM}{DD}` → `20240315`
- `{era}{eyear}年{M}月{D}日（{W}）` → `令和6年3月15日（金）`（和暦出力の既定）
- `{abbr}{eyear}.{MM}.{DD}` → `R6.03.15`

不明なトークンや `{ }` の不一致、年のトークンが無いテンプレートは、設定画面にエラーを表示して保存しません。

日まで入力していないときは、無い部分と区切りが省かれます（`{YYYY}/{M}/{D}` → `2024/3`、`{YYYY}年{M}月{D}日` → `2024年3月`）。曜日が出せないとき（日まで無い・明治5年以前の旧暦）は、`（{W}）` の括弧ごと消えます。年・月・日の順に書いてください。

## インストール（開発者モード）
`chrome://extensions` → デベロッパーモード → 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択。

## テスト
`npm test`（Node 18+、変換ロジックのみ）
