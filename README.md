# 和暦⇔西暦 変換（Chrome拡張）

ページ上で和暦または西暦を選択すると、近くにツールチップで変換結果を表示します。ツールチップをクリックするとクリップボードにコピーします。

- 例: `令和6年3月15日` → `2024年3月15日（金）` / `2024/3/15` → `令和6年3月15日（金）`
- 日付まで含む場合は曜日も表示（明治5年以前は旧暦のため表示しません）
- 改元をまたぐ年・月は両方の元号を併記（`1989年` → `平成元年／昭和64年`）
- 存在しない年・日付、元号の範囲外は警告を表示
- 対応書式: `令和6年` `令和元年3月` `R6` `平3` `2024年3月` `2024/3/15` `2024-03-15` `2024.3.15` など
- 漢数字（`令和六年三月十五日` `二〇二四年` `明治二十五年` `廿五`）に対応
- 江戸時代の元号（慶長〜慶応）に対応。旧暦のため**年のみ換算**し、月日は換算しません（`嘉永6年 → 1853年`、`1864年 → 元治元年／文久4年`）
- 全角数字・全角記号（`令和６年３月１５日`、`２０２４／３／１５`）や `㋿` `㍻` などの合字にも対応

## 出力書式の設定
拡張機能の「オプション」（`chrome://extensions` → 詳細 → 拡張機能のオプション、または拡張機能アイコンの右クリック → オプション）で変更できます。変更はすぐ保存され、Chromeにログインしていれば他の端末にも同期されます。

| 項目 | 選べるもの |
|---|---|
| 区切り文字 | 年月日 `2024年3月15日` / スラッシュ `2024/3/15` / ドット `2024.3.15` / ハイフン `2024-3-15` / なし `20240315` |
| 0埋め | 月日を2桁に（`2024/03/05`）。区切り「なし」は常に2桁 |
| 曜日 | `（金）` / `(金)` / `金曜日` / 表示しない。コピーに曜日を含めるかも選択可 |
| 和暦の書式 | `令和6年` / 略記 `R6`（月日は `R6.3.15`）。1年を「元年」とするか「1年」とするか |

書式は西暦→和暦・和暦→西暦の両方の結果に適用されます。

## インストール（開発者モード）
`chrome://extensions` → デベロッパーモード → 「パッケージ化されていない拡張機能を読み込む」でこのフォルダを選択。

## テスト
`npm test`（Node 18+、変換ロジックのみ）
