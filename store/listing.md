# Chromeウェブストア掲載用テキスト

## 名前（最大75文字）
和暦⇔西暦 変換

## 概要（最大132文字／manifest.json の description と同じ）
和暦・西暦の日付を選択すると、変換結果と曜日をその場でツールチップ表示。クリックでコピー。改元年は両方の元号を併記。

## 詳細説明
ウェブページ上の和暦または西暦を選択するだけで、変換結果をすぐ近くにツールチップで表示します。ツールチップをクリックすると、結果をクリップボードにコピーできます。

【できること】
・和暦 → 西暦、西暦 → 和暦の相互変換
　例: 令和6年3月15日 → 2024年3月15日（金）
　例: 2024/3/15 → 令和6年3月15日（金）
・日付まで選択した場合は曜日も表示
・改元をまたぐ年・月は両方の元号を併記（1989年 → 平成元年／昭和64年）。日付まで選べば1つに確定します
・存在しない年や日付、元号の範囲外は警告を表示（昭和70年、令和6年2月30日 など）
・全角数字・全角記号（令和６年３月１５日、２０２４／３／１５）や ㋿ ㍻ ㍼ などの合字にも対応
・漢数字（令和六年三月十五日、二〇二四年、明治二十五年）に対応
・江戸時代の元号（慶長〜慶応）に対応（旧暦のため年のみ換算。嘉永6年 → 1853年）
・入力欄（テキストボックス）内の選択やiframe内でも動作

【対応する書式】
令和6年 ／ 令和元年3月 ／ R6 ／ H31 ／ 平3 ／ 2024年3月 ／ 2024/3/15 ／ 2024-03-15 ／ 2024.3.15 など

【注意】
・明治5年（1872年）以前は旧暦のため、年のみ換算し、月日の換算と曜日表示は行いません。
・慶長より前の元号（室町時代以前）には対応していません。
・Chromeウェブストア、chrome:// ページなど、Chromeが拡張機能の動作を許可していないページでは動きません。

【プライバシー】
選択した文字列は、ブラウザ内での変換にのみ使用します。外部への送信・保存・収集は一切行いません。

## 単一の目的（Single purpose）
ページ上で選択した和暦・西暦の日付を相互に変換して表示し、コピーできるようにする。

## 権限の理由
- 権限（permissions）: なし。
- コンテンツスクリプト（全URL・全フレーム）: ユーザーが任意のページ上で日付を選択した時点で、その選択文字列を読み取り、変換結果をツールチップで表示するために必要です。ページ内容の変更・収集・送信は行いません。

## データ使用の申告（Privacy practices）
- 収集するデータ: なし（個人を特定できる情報、健康、財務、認証情報、位置情報、閲覧履歴、ユーザーの操作、ウェブサイトのコンテンツ のいずれも収集しない）
- 選択文字列はブラウザ内で処理し、外部送信・保存しない
- リモートコードの使用: なし
- プライバシーポリシーURL: 欄に入力が求められる場合は、README等の公開ページのURLを指定
