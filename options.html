出力書式

変換結果の表示とコピーに使う書式です。書式テンプレートを自由に書けます。変更はすぐ保存されます。

西暦で出力するとき（和暦 → 西暦）

例: 令和6年3月5日 を変換した結果

挿入:
和暦で出力するとき（西暦 → 和暦）

例: 2024/3/5 を変換した結果

テンプレートの書き方

出力したい形を、トークンを { } で囲んで書きます。{ } の外に書いた文字は、そのまま出力されます。トークンの大文字小文字は区別しません（{yyyy} も可）。

トークン出力
{YYYY}西暦4桁（2024）
{era} / {abbr}元号名（令和） / 略記（R）
{eyear} / {eyear2}和暦の年（6、元年は「元」） / 2桁（06）
{M} / {MM}月（3） / 2桁（03）
{D} / {DD}日（5） / 2桁（05）
{W} / {WW}曜日（金） / 曜日の名前（金曜日）
{{ / }}文字としての { と }

例: {YYYY}/{MM}/{DD}({W}) → 2024/03/15(金)、{abbr}{eyear}.{MM}.{DD} → R6.03.15
年・月・日の順に書いてください。年のトークンを1つ以上含める必要があります（60文字まで）。
日まで入力していないときは、{YYYY}/{M}/{D} なら 2024/3、{YYYY}年{M}月{D}日 なら 2024年3月 のように、無い部分と区切りが省かれます。 曜日が出せないとき（日まで無い・明治5年以前の旧暦）は、（{W}） の括弧ごと消えます。
